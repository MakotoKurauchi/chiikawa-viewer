# ちいかわ まんがビューア

[@ngnchiikawa](https://x.com/ngnchiikawa) の投稿を一覧して読む、非公式のファンメイドビューアです。各話から X 上の元投稿へリンクします。

公開ページ: <https://makotokurauchi.github.io/chiikawa-viewer/>

まんがの画像はこのリポジトリには置いていません。表示のたびに X（`pbs.twimg.com`）から読み込みます。作品の権利は権利者に帰属します。

## できること

- **一覧・ビューア**：サムネイルの一覧から話を開き、スワイプやキーボードで画像・話を移動できます。ことば検索、年・月のしぼりこみ、新しい順／古い順／いいね順、🎲 ランダム、前回のつづきから再開。
- **🔖 しおり・既読**：話にしおりをはさめます。開いた話には「✓既読」がつき、「未読のみ」で未読だけを表示できます。「▶ 続きから読む」で、メインのしおりの次の未読から読めます。
- **⭐ お気に入り**：カードの右下やビューア上部の ☆ をタップすると、お気に入りに追加できます。「⭐ お気に入り」にチェックすると、お気に入りだけを一覧表示します。
- **📅 年表（カレンダー）**：年ごと・月ごとの話数と、読んだ割合（既読 x/y）を表示します。月をタップするとその月の話だけ、年をタップするとその年の話だけを表示します。🆕 新着・🔖 しおり・⭐ お気に入りがある月には印がつきます。
- **🆕 新着（NEW）**：前回ひらいたあとに追加された話に「NEW」の印がつき、「🆕 新着 N話」で新着だけを表示できます。印は、その話を開くか「✓ 確認済み」をおすと消えます（開かないままの NEW は最大 14 日間残ります）。はじめて開いたときは、すべてが NEW にはならず、その時点の最新話を基準として記録するだけです。
- **💾 バックアップ**：しおり・お気に入り・既読は、ブラウザ内（localStorage）に保存されます。「🔖 しおり → 💾 バックアップ → 📋 コピー」で作ったコードを、別の端末やブラウザで「📥 読み込み」すると引き継げます。お気に入りを含むコードは `CK2.` から、お気に入りがない場合は従来どおり `CK1.` からはじまります。以前の `CK1.` コードもそのまま読み込めます。
- **JavaScript なしでも表示**：iOS のファイルのプレビューなど JavaScript が動かない環境では、年月の目次つきのかんたんな一覧を表示します。

## iPhone のホーム画面に追加する

1. iPhone の **Safari** で公開ページをひらきます。
2. 画面下（iPad では上）の **共有ボタン**（四角から上向きの矢印が出ているアイコン）をタップします。
3. **「ホーム画面に追加」** を選び、右上の「追加」をタップします。

ホーム画面の「ちいかわビューア」アイコンから、アドレスバーのない全画面で読めます。データは毎日更新されるので、開くたびに最新の内容になります（オフラインでは使えません）。

> **ご注意**：iPhone では、ホーム画面から開いたアプリと Safari とで、しおり・お気に入り・既読の保存場所が別々です。Safari で使っていたしおりなどをアプリ側に移すには、Safari 側で「🔖 しおり → 💾 バックアップ → 📋 コピー」し、アプリ側の「📥 読み込み」にコードを貼りつけてください。

## 更新のしかた

`index.html` は、リポジトリ外のローカル SQLite データベースから再生成し、そのファイルを差し替えて更新します。データベース自体はここには含まれません。再生成に使うスクリプトは参照用に `tools/build_viewer.py` を置いてあります。

```bash
python3 tools/build_viewer.py --db /path/to/chiikawa_manga.db --out index.html
```

生成した `index.html` をコミットして `main` に入れると、GitHub Pages の内容が更新されます。

ホーム画面アプリ用の次のファイルは、リポジトリのルートに一度だけ置いてあり、毎日の更新では変わりません（`index.html` から相対パスで参照しています）。

| ファイル | 内容 |
| --- | --- |
| `manifest.webmanifest` | Web アプリマニフェスト（名前「ちいかわビューア」、standalone 表示） |
| `apple-touch-icon.png` | iPhone のホーム画面用アイコン（180×180） |
| `icon-192.png` / `icon-512.png` | そのほかの環境用アイコン |

アイコンは、このビューアのためにつくったオリジナルの図案（パステル調の本としおり）で、キャラクターの絵は使っていません。

## GitHub Pages

リポジトリの Settings → Pages で、次のとおり設定します。

- **Deploy from a branch**
- Branch: **main**
- Folder: **/ (root)**

ルートの空ファイル `.nojekyll` により、Jekyll の処理を無効にしています。
